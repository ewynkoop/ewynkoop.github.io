# ewynkoop.github.io

Personal portfolio for Ellie Wynkoop. Plain HTML/CSS/JS with no build step.

- **Add or edit a project:** open `projects.js` and copy an existing block (instructions are at the top of the file).
- **Add photos/videos:** drop them in `assets/projects/<project-id>/` using the filenames listed in `projects.js`. Until a file exists, the site shows a "coming soon" placeholder with the expected path.
- **Profile photo:** `assets/profile.jpg` · **Résumé:** `assets/resume.pdf`
- **Preview locally:** `python3 -m http.server` then open http://localhost:8000
